Games

Small text games a Yendory model plays through Nexus: it sees the game's rules, looks to see the position, makes a move, and gets the result back, the way it will later use apps. Every game has a perfect player, so every move the model makes can be graded.

Play

A game between the open model and the perfect player, a random player, or you. Step through it turn by turn and see what the model wrote: the actions it took, the results it got, and how each move compares with the perfect player's.

The game, as the model saw it

Lessons

The perfect player's turns, written as lessons: in each, it looks, makes the best move and replies, exactly as the model will be asked to. One position in ten is held out and never written, so the Scoreboard can tell whether a model plays well where it was never taught.

Teaching

Tools will teach these lessons through the Yendory Network once the Network can train (its training job is on the way); the Hub will update the Network, and this button will start. Until then, the saved file is a Multi-Turn Conversation lesson, the format Studio's Classroom reads, with Nexus's Environment, Action and Result lines.

Scoreboard

The open model plays a game many times, half the games going first. Every move is graded: legal or not, and whether it is the perfect player's. The last columns count only held-out positions, never in any lesson, so they show what the model learned rather than what it memorised.

Apps

Apps come after games: tools a model uses through Nexus the same way it plays, such as a calculator or a notebook, where it acts, reads the result and answers. Games come first because every move in them can be graded.
