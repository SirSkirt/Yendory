§The Yendory Network

Every Yendory program works on models through the Yendory Network, a small program that runs the Yendory Engine in the background. The Hub installs it and keeps it updated; it starts when a program needs it and stops when none does.

Models

§New model

An untrained model, made by the Yendory Engine exactly as Studio makes one, and saved in the models folder every program reads. Teach it conversation in Studio, games in Yendory Tools, or both.

Brain

A Nova Neuro brain is made of networks that each do one kind of work and talk through a shared communication bus. Take one network, all of them, or any mix, each as large as you like: the Engine sizes each network as close as it can to what you choose and shows its exact count.

The width every network reads and writes: the words' vectors, the transformer and the bus. Wider networks hold more in each step and cost more for the same depth.

§Downloads & updates

Everything the Hub installs and keeps up to date. It downloads each part from the project's release page, checks its signature, and installs it itself: no installer windows.

PartInstalledNewest

Updating the Network asks the programs using it to be closed first. Updating Studio keeps your models, datasets, chats and settings: they live in Studio's data folder, not with the program.

Models live in Studio's models folder, and every program reads them from there through the Yendory Network. The programs folder holds what the Hub installed. The Hub's folder holds your shelves and its settings; removing it forgets the shelves, never the models.

Where the programs are

The Hub knows the programs it installed. It also finds ones installed on their own in the usual places; if yours is somewhere else, choose its file (then it can be switched to the Hub too).
